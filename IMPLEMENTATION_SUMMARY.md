## 🚀 How to Run

### Development
```bash
npm install
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000)

### Build for Production
```bash
npm run build
npm run lint  # Check for errors
npm start     # Run production server
```

### Deployment
- **Vercel (Recommended)**: Connect GitHub repo to Vercel for automatic deployment
- **Other**: Works with any Node.js hosting (Netlify, AWS, Digital Ocean, etc.)
